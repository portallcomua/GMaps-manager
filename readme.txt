=== GMaps Client Manager ===
Version: 2.0.0

Менеджери працюють з Google Maps клієнтів через ваш центральний Google-акаунт — власні ключі їм не потрібні.

== Швидкий старт ==
1. Налаштування: Places API key, OAuth Client ID/Secret, посилання на Приват Конверт, відсоток комісії, Google-пошта центрального акаунта.
2. «Підключити Google-акаунт», потім «Перевірити налаштування» (діагностика).
3. Менеджер реєструється на /gmaps/ (або шорткод [gmaps_manager_register]); ви призначаєте роль на вкладці «Менеджери».
4. Кабінет менеджера: /gmaps/ (шорткод [gmaps_client_manager], кнопка [gmaps_manager_link]).

== Важливо ==
* Business Profile API потребує схвалення доступу від Google (запит у Google Cloud), інакше квота = 0.
* Нова картка видима на Maps лише після верифікації Google.
* API приймає лише фото; відео зберігаються в роботі й додаються вручну.
* Публічна форма заявок з 1.4 прибрана (старі заявки лишились в архіві адмінки).
* Відгуки: плагін дає лише посилання й тексти для справжніх клієнтів.
